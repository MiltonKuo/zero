1 RT = 3.517 kW；COP = 冷量/功率；EER = COP×3.412（英制 btu/W）；kW/RT = 3.517/COP
① 效率單位互換
COP = Q_cool(W) / P_in(W)
EER = COP × 3.412（btu/hr/W）
kW/RT = 3.517 / COP
W/RT = 3517 / COP
冰機效率常用 COP（無因次）、kW/RT（每冷吨耗電）、EER（英制）三單位。依任一值可換其他單位

PLR（部分負載）效率：
冰機在 70~80% 負載時效率最高（IPLV 考量 100/75/50/25% 四檔加權）。 IPLV 通常較全負載 kW/RT 改善 10~20%。ESCO 驗證時需以實際運轉負載分佈計算。
判定標準：ESCO 冰機案目標 kW/RT ≤ 0.90（全負載）屬高頻；≤ 1.00 屬中頻；> 1.20 屬低效升級
⑤ IPLV 速算
IPLV = 400 ÷ (2×COP₁₀₀ + 6×COP₇₅ + 6×COP₅₀ + 3×COP₂₅)
各負載 COP 越高越好（IPLV 為加權 COP）
ASHRAE 90.1 加權：100%×20%、75%×30%、50%×40%、25%×10%。IPLV（COP 值）越高代表部分負載效率越好；COP 約 3.5 以上屬中頻、4.0 以上屬高效
